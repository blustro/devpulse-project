# DevPulse - Phase 1: GraphQL Foundations

Welcome to Phase 1 of DevPulse! This project introduces core GraphQL concepts by building a lightweight task manager server using Node.js and Apollo Server.

## 🛠️ Tech Stack

- **Runtime:** Node.js (with ES Modules)
- **Server Engine:** Apollo Server v4 (`@apollo/server`)
- **Data Store:** In-memory JavaScript array (RAM)

---

## 🚀 How to Run the Backend

1. Install dependencies:
   ```bash
   npm install
   ```
